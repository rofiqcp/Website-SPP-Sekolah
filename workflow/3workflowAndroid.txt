Bisa dibuat **tanpa program tambahan di PC client**, tapi harus dipilih jalur hardware yang benar. Catatan pentingnya:

1. **Web biasa tidak bisa diam-diam membaca semua port USB tanpa izin.**
2. Untuk reader RFID mode **keyboard/HID**, web bisa langsung membaca seperti input keyboard.
3. Untuk reader/writer RFID mode **serial/COM port**, web bisa pakai **Web Serial API** di Chrome/Edge desktop.
4. Untuk reader/writer tipe **PC/SC seperti sebagian NFC reader**, biasanya web tidak bisa akses langsung tanpa bridge/native app.
5. Jadi kalau targetnya “tinggal login dari web, tidak instal apa-apa”, maka dari awal harus beli RFID reader/writer yang cocok.

Web Serial memang memungkinkan website berkomunikasi dengan perangkat serial melalui JavaScript, termasuk USB/Bluetooth yang meniru serial port, tetapi fiturnya terbatas pada browser tertentu dan wajib secure context/HTTPS. ([Chrome for Developers][1]) Browser juga mewajibkan user gesture untuk memilih port pertama kali; setelah izin diberikan, web bisa memakai daftar port yang sebelumnya sudah diizinkan dengan `navigator.serial.getPorts()`. ([Chrome for Developers][1])

# 1. Keputusan Desain yang Saya Sarankan

Untuk El Yaomy, gunakan **3 mode RFID**.

## Mode A — RFID Reader Keyboard / HID

Ini paling mudah untuk kantin.

```text
RFID reader USB dicolok ke PC
Reader bertindak seperti keyboard
Saat kartu ditempel, UID diketik otomatis ke input web
Web langsung proses pembayaran
Tidak perlu port
Tidak perlu Web Serial
Tidak perlu aplikasi tambahan
```

Kelebihan:

```text
- Paling mudah
- Sangat stabil
- Bisa dipakai di Chrome, Edge, Firefox
- Cocok untuk kasir kantin
- Tidak perlu izin port browser
```

Kekurangan:

```text
- Umumnya hanya read UID
- Tidak cocok untuk tulis data ke kartu
- Keamanan tergantung server, limit, dan audit
```

Rekomendasi penggunaan:

```text
Kantin harian
Cek saldo siswa
Pembayaran cepat
Top-up sederhana
Scan kartu siswa
```

---

## Mode B — RFID Reader/Writer Serial via Web Serial

Ini untuk fitur reader/writer yang benar-benar ingin diakses dari web.

```text
RFID reader/writer USB mendukung virtual COM port
Web pakai Web Serial API
User login
Klik "Hubungkan Reader"
Browser minta izin port pertama kali
Setelah itu web bisa auto-connect port yang sudah pernah diizinkan
```

Kelebihan:

```text
- Tetap tanpa aplikasi tambahan
- Bisa baca dan tulis jika reader punya command serial
- Bisa deteksi vendor/product ID tertentu
- Cocok untuk admin kartu
```

Kekurangan:

```text
- Harus Chrome/Edge desktop
- Harus HTTPS atau localhost
- User tetap harus memberi izin port pertama kali
- Tidak semua reader RFID cocok
```

Rekomendasi penggunaan:

```text
Penerbitan kartu
Cek kartu
Aktivasi kartu
Blokir/ganti kartu
Tulis token jika hardware mendukung
```

---

## Mode C — Native Bridge

Ini **jangan dipakai dulu** kalau ingin sederhana.

```text
RFID reader PC/SC
Aplikasi kecil lokal membaca kartu
Web menerima data dari aplikasi lokal
```

Kelebihan:

```text
- Kompatibel dengan banyak reader profesional
- Lebih kuat untuk DESFire/security card
```

Kekurangan:

```text
- Harus instal program tambahan
- Tidak sesuai keinginan Anda saat ini
```

Kesimpulan saya:

```text
Untuk MVP:
- Kantin pakai RFID keyboard/HID.
- Admin kartu pakai Web Serial reader/writer jika butuh tulis kartu.
- Saldo tetap di server, bukan di kartu.
```

# 2. Cara Supaya “Tinggal Login” dari Web

Flow ideal di PC client:

```text
1. Petugas buka web sekolah.otomasi.app
2. Login sebagai kasir/admin/guru
3. Sistem membaca role user
4. Sistem membaca terminal/browser yang sedang dipakai
5. Sistem mencoba auto-connect reader:
   - jika mode HID: langsung fokus ke input scan
   - jika mode Serial: cek port yang pernah diizinkan
6. Jika belum pernah izin port, tampil tombol "Hubungkan Reader"
7. Setelah reader aktif, user langsung bisa transaksi
```

Catatan penting:

```text
Auto-detect penuh hanya bisa untuk reader yang sudah pernah diberi izin.
Untuk reader serial baru, browser tetap meminta user memilih port.
Itu aturan keamanan browser, tidak bisa dilewati.
```

# 3. Rekomendasi Hardware RFID

## Untuk kasir kantin

Gunakan:

```text
RFID USB 13.56 MHz
Mode keyboard / HID
Output UID + Enter
Bisa setting prefix/suffix
Tidak perlu driver tambahan
```

Setting reader:

```text
Output format : HEX uppercase
Suffix        : Enter
Prefix        : kosong atau "RFID:"
Debounce      : 1-2 detik
```

Contoh output:

```text
04A1B2C3D4
```

atau:

```text
RFID:04A1B2C3D4
```

## Untuk admin kartu / writer

Gunakan reader/writer yang:

```text
Mendukung virtual COM port
Punya dokumentasi command serial
Bisa baca UID
Bisa tulis block/sector/token bila dibutuhkan
Kompatibel Chrome Web Serial
```

Hindari untuk web-only:

```text
Reader yang hanya PC/SC tanpa mode serial
Reader yang butuh aplikasi vendor
Reader yang butuh driver khusus berat
Reader yang command protocol-nya tertutup
```

## Mode RFID Keyboard / HID

Ini paling mudah dan sangat cocok untuk kantin.

```text
FUNCTION start_keyboard_rfid_listener():
    create_hidden_input("rfid_input")
    focus("rfid_input")

    ON input keydown:
        collect characters into buffer

        IF key == "Enter":
            raw_uid = buffer.trim()
            buffer = ""

            IF is_valid_rfid(raw_uid):
                handle_card_scanned(raw_uid)
```

Anti double scan:

```text
FUNCTION handle_card_scanned(raw_uid):
    normalized_uid = normalize_uid(raw_uid)

    IF same_uid_scanned_within_2_seconds(normalized_uid):
        IGNORE

    current_context = get_current_page_context()

    IF current_context == "canteen_pos":
        process_canteen_card(normalized_uid)

    IF current_context == "topup":
        process_topup_card(normalized_uid)

    IF current_context == "card_management":
        process_card_management_scan(normalized_uid)
```

## Mode Web Serial Auto Connect

Pertama kali user tetap perlu klik “Hubungkan Reader”.

```text
FUNCTION connect_serial_reader_first_time():
    REQUIRE user clicks button

    IF "serial" not in navigator:
        show_error("Browser tidak mendukung Web Serial")
        RETURN

    port = navigator.serial.requestPort({
        filters: [
            { usbVendorId: RFID_VENDOR_ID_OPTIONAL }
        ]
    })

    open_serial_port(port)
    save_reader_mode("serial")
```

Auto connect berikutnya:

```text
FUNCTION try_auto_connect_previous_serial_reader():
    ports = navigator.serial.getPorts()

    IF ports.length == 0:
        show_status("Reader serial belum dihubungkan")
        RETURN

    FOR port IN ports:
        TRY:
            open_serial_port(port)
            show_status("Reader serial aktif")
            RETURN
        CATCH:
            continue

    show_status("Reader serial gagal auto-connect")
```

Chrome menjelaskan bahwa `requestPort()` memunculkan pilihan perangkat, sedangkan `getPorts()` mengambil port yang sebelumnya sudah diberi akses oleh user. ([Chrome for Developers][1])

## Open port serial

```text
FUNCTION open_serial_port(port):
    port.open({
        baudRate: 9600,
        dataBits: 8,
        stopBits: 1,
        parity: "none",
        flowControl: "none"
    })

    reader = port.readable.getReader()

    WHILE port is open:
        data = reader.read()
        text = decode_serial_bytes(data.value)

        append text to serial_buffer

        IF serial_buffer contains complete RFID frame:
            raw_uid = parse_uid(serial_buffer)
            serial_buffer = ""

            handle_card_scanned(raw_uid)
```

## Pseudocode tulis kartu via Web Serial

Hanya bisa jika reader/writer menyediakan command serial.

```text
FUNCTION write_card_token_via_serial(card_token):
    IF serial_port_not_connected:
        REJECT "Reader writer belum aktif"

    command = build_write_command(card_token)

    checksum = calculate_checksum(command)

    frame = command + checksum

    serial_writer.write(frame)

    response = wait_serial_response(timeout = 3000)

    IF response.status == "OK":
        RETURN success
    ELSE:
        REJECT "Gagal menulis kartu"
```

Catatan saya: untuk keamanan, **tidak wajib menulis saldo ke kartu**. Bahkan lebih aman kalau kartu hanya dipakai sebagai identitas. Jika ingin menulis token, tulis token acak, bukan saldo.

# 6. Backend API untuk RFID Web

## Endpoint scan kartu

```text
POST /api/rfid/scan
```

Payload:

```text
{
  "raw_uid": "04A1B2C3D4",
  "mode": "hid_keyboard",
  "terminal_id": "terminal-kantin-01",
  "context": "canteen_pos"
}
```

Backend:

```text
FUNCTION rfid_scan(request):
    user = authenticate(request)

    validate_terminal(request.terminal_id, user)

    uid_hash = hmac_sha256(SERVER_SECRET, normalize_uid(request.raw_uid))

    card = find_card_by_uid_hash(uid_hash)

    IF card not found:
        RETURN {
            status: "unknown_card"
        }

    IF card.status != "active":
        RETURN {
            status: "blocked_card",
            reason: card.blocked_reason
        }

    student = get_student(card.student_id)
    wallet = get_wallet(student.id)

    authorize(user, "rfid.scan", student)

    log_card_event(card, user, terminal)

    RETURN {
        status: "active",
        student: {
            id,
            name,
            class_name,
            photo_url
        },
        wallet: {
            balance,
            daily_limit,
            today_spent
        }
    }
```

# 7. Terminal Web Tanpa Program Tambahan

Karena tidak ada aplikasi lokal, kita tetap perlu mengenali PC client. Caranya:

```text
Terminal Enrollment berbasis browser
```

## Alur register terminal

```text
1. Super admin login di PC client
2. Buka menu Terminal
3. Klik "Daftarkan PC ini"
4. Pilih lokasi:
   - Kantin 1
   - Admin TU
   - Kasir Sekolah
5. Browser membuat private key non-extractable via Web Crypto
6. Public key dikirim ke server
7. Server menyimpan terminal_id + public_key
8. Terminal aktif
```

Pseudocode:

```text
FUNCTION enroll_terminal(admin, terminal_name, location, allowed_modules):
    authorize(admin, "terminal.enroll")

    keypair = crypto.subtle.generateKey(
        algorithm = ECDSA_P256,
        extractable = false,
        usages = ["sign", "verify"]
    )

    public_key = export_public_key(keypair.publicKey)

    save_private_key_to_indexeddb(keypair.privateKey)

    response = POST /api/terminals/enroll {
        terminal_name,
        location,
        allowed_modules,
        public_key
    }

    save_terminal_id_to_indexeddb(response.terminal_id)
```

## Saat transaksi

```text
FUNCTION send_secure_terminal_request(payload):
    terminal_id = get_terminal_id_from_indexeddb()
    private_key = get_private_key_from_indexeddb()

    nonce = get_nonce_from_server()

    signature = sign(private_key, hash(payload + nonce))

    POST API with:
        X-Terminal-Id
        X-Terminal-Signature
        X-Terminal-Nonce
```

Backend:

```text
FUNCTION verify_terminal_request(request):
    terminal = get_terminal(request.terminal_id)

    IF terminal.status != "active":
        REJECT

    IF terminal.allowed_modules does not contain request.module:
        REJECT

    verify_signature(
        public_key = terminal.public_key,
        payload_hash = hash(request.body + request.nonce),
        signature = request.signature
    )

    IF signature invalid:
        REJECT
```

Ini lebih aman daripada hanya menyimpan token biasa di browser.

# 12. MainActivity Kotlin Pseudocode

```kotlin
class MainActivity : AppCompatActivity() {

    private lateinit var webView: WebView
    private val appUrl = "https://sekolah.otomasi.app"

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)

        webView = WebView(this)
        setContentView(webView)

        configureWebView()
        configureNavigation()
        configureDownload()

        webView.loadUrl(appUrl)
    }

    private fun configureWebView() {
        val settings = webView.settings

        settings.javaScriptEnabled = true
        settings.domStorageEnabled = true
        settings.databaseEnabled = true

        settings.allowFileAccess = false
        settings.allowContentAccess = false

        settings.setSupportZoom(false)
        settings.builtInZoomControls = false
        settings.displayZoomControls = false

        settings.mixedContentMode = WebSettings.MIXED_CONTENT_NEVER_ALLOW

        WebView.setWebContentsDebuggingEnabled(false)

        CookieManager.getInstance().setAcceptCookie(true)
        CookieManager.getInstance().setAcceptThirdPartyCookies(webView, false)
    }

    private fun configureNavigation() {
        webView.webViewClient = object : WebViewClient() {

            override fun shouldOverrideUrlLoading(
                view: WebView,
                request: WebResourceRequest
            ): Boolean {
                val url = request.url.toString()
                val host = request.url.host ?: ""

                return if (host == "sekolah.otomasi.app") {
                    false
                } else {
                    openExternalBrowser(url)
                    true
                }
            }

            override fun onReceivedSslError(
                view: WebView,
                handler: SslErrorHandler,
                error: SslError
            ) {
                handler.cancel()
                showError("Koneksi tidak aman. Aplikasi diblokir.")
            }
        }

        webView.webChromeClient = object : WebChromeClient() {
            override fun onPermissionRequest(request: PermissionRequest) {
                request.deny()
            }
        }
    }

    private fun configureDownload() {
        webView.setDownloadListener { url, userAgent, contentDisposition, mimeType, contentLength ->

            if (!url.startsWith("https://sekolah.otomasi.app")) {
                showError("Download dari domain lain diblokir")
                return@setDownloadListener
            }

            val request = DownloadManager.Request(Uri.parse(url))
            request.setTitle(resolveFileName(contentDisposition, url))
            request.setMimeType(mimeType)
            request.addRequestHeader("User-Agent", userAgent)
            request.setNotificationVisibility(
                DownloadManager.Request.VISIBILITY_VISIBLE_NOTIFY_COMPLETED
            )
            request.setDestinationInExternalPublicDir(
                Environment.DIRECTORY_DOWNLOADS,
                resolveFileName(contentDisposition, url)
            )

            val manager = getSystemService(DOWNLOAD_SERVICE) as DownloadManager
            manager.enqueue(request)
        }
    }

    override fun onBackPressed() {
        if (webView.canGoBack()) {
            webView.goBack()
        } else {
            super.onBackPressed()
        }
    }

    private fun openExternalBrowser(url: String) {
        val intent = Intent(Intent.ACTION_VIEW, Uri.parse(url))
        startActivity(intent)
    }
}
```

# 13. Jangan Sembarangan Pakai JavaScript Interface

Untuk WebView HP, sebaiknya **tidak perlu `addJavascriptInterface()`** dulu.

Kenapa?

Android Developers memperingatkan bahwa `addJavascriptInterface()` memungkinkan JavaScript mengontrol bagian aplikasi Android dan bisa menjadi isu keamanan jika HTML/JavaScript tidak sepenuhnya terpercaya. ([Android Developers][3])

Jadi untuk versi awal:

```text
Tidak perlu JavaScript bridge
Tidak perlu akses native Android
Cukup WebView aman
Semua fitur dari website
```

Kalau nanti butuh push notification, kamera, atau file khusus, baru dibuat bridge terbatas.

FUNCTION checkAppUpdate():
    latest = httpGet("https://sekolah.otomasi.app/api/mobile-app/latest")

    currentVersionCode = BuildConfig.VERSION_CODE

        showForceUpdateDialog(latest.apk_url)

    ELSE IF latest.version_code > currentVersionCode:

    ELSE:

## Upload release

```text
FUNCTION upload_android_release(admin, apk_file, metadata):
    authorize(admin, "mobile_release.upload")

    validate_file_extension(apk_file, ".apk")
    validate_mime_type(apk_file)
    scan_file_for_malware(apk_file)

    sha256 = calculate_sha256(apk_file)

    store_file(apk_file, "/downloads/el-yaomy-{version}.apk")

    mark_old_latest_false()

    insert mobile_app_release:
        version_code
        version_name
        apk_path
        sha256
        changelog
        is_latest = true

    audit(admin, "mobile_release.upload")
```

# 22. Pseudocode Checkout Kantin Final

```text
FUNCTION checkout_canteen_rfid(user, terminal, raw_uid, cart):
    authenticate(user)
    authorize(user, "canteen.checkout")
    authorize_terminal(terminal, "canteen")

    uid_hash = hmac_sha256(SERVER_SECRET, normalize_uid(raw_uid))

    card = find_active_card(uid_hash)

    IF card not found:
        REJECT "Kartu tidak dikenal"

    IF card.status != "active":
        REJECT "Kartu tidak aktif"

    student = get_student(card.student_id)
    wallet = get_wallet(student.id)

    total = calculate_cart_total(cart)

    IF total <= 0:
        REJECT "Keranjang kosong"

    IF exceeds_daily_limit(student.id, total):
        REJECT "Melebihi limit harian"

    idempotency_key = request.header["X-Idempotency-Key"]

    IF idempotency_exists(idempotency_key):
        RETURN previous_result

    BEGIN_TRANSACTION
        lock wallet row FOR UPDATE

        IF wallet.cached_balance < total:
            REJECT "Saldo tidak cukup"

        order = create_canteen_order(
            student_id = student.id,
            user_id = user.id,
            terminal_id = terminal.id,
            total = total,
            status = "paid"
        )

        FOR each item in cart:
            lock product stock
            decrease stock
            create order item

        create_wallet_transaction(
            wallet_id = wallet.id,
            type = "canteen_payment",
            amount = total,
            source_id = order.id
        )

        create_wallet_ledger(
            wallet_id = wallet.id,
            direction = "debit",
            amount = total,
            balance_before = wallet.cached_balance,
            balance_after = wallet.cached_balance - total
        )

        update wallet.cached_balance = wallet.cached_balance - total

        create_accounting_journal_for_canteen(order)

        create_audit_log(user, "canteen.checkout.rfid", order.id)

        save_idempotency_result(idempotency_key, order)
    COMMIT

    notify_parent_async(student.id, order)

    RETURN order
```

# 23. Alur Top-up dari Web

```text
1. Admin/guru login
2. Buka menu Top-up
3. Scan kartu siswa
4. Web tampilkan siswa
5. Input nominal
6. Backend cek role:
   - guru hanya kelasnya
   - admin sesuai unitnya
   - bendahara semua unit
7. Backend cek limit
8. Jika nominal besar, minta password/PIN ulang
9. Simpan transaksi
10. Tambah saldo wallet
11. Simpan ledger
12. Simpan jurnal
13. Cetak struk
14. Notifikasi orang tua
```

Pseudocode:

```text
FUNCTION topup_wallet_from_web(user, terminal, raw_uid, amount, method):
    authenticate(user)
    authorize(user, "wallet.topup")
    authorize_terminal(terminal, "topup")

    card = find_card_by_hashed_uid(raw_uid)

    IF card.status != "active":
        REJECT

    student = get_student(card.student_id)

    IF user.role == "teacher":
        IF student.class_id not in user.allowed_classes:
            REJECT "Tidak boleh top-up siswa di luar kelas"
        IF amount > TEACHER_TOPUP_LIMIT:
            REJECT "Melebihi limit guru"

    IF amount >= REAUTH_AMOUNT_LIMIT:
        require_reauthentication(user)

    BEGIN_TRANSACTION
        lock wallet row FOR UPDATE
        create topup transaction
        create wallet ledger credit
        update wallet balance
        create cash movement if method == cash
        create journal:
            Debit Kas
            Kredit Titipan Saldo Dompet Siswa
        audit log
    COMMIT

    send notification
```

# 24. Catatan Penting Tentang “Reader Writer”

Saya sarankan jangan terlalu bergantung pada fitur tulis kartu.

Lebih aman:

```text
Kartu hanya menyimpan UID/token
Saldo tetap di PostgreSQL
Data siswa tetap di PostgreSQL
Limit tetap di PostgreSQL
Status kartu tetap di PostgreSQL
```

Kalau butuh “writer”, gunakan hanya untuk:

```text
Menulis card public token
Menulis identitas non-sensitif
Menulis konfigurasi kartu
Bukan menulis saldo
Bukan menulis password
Bukan menulis data pribadi lengkap
```
